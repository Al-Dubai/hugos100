# 001: Hello Console 👋

**Concept:** `console.log` · **Difficulty:** ★☆☆☆☆

## Goal

Make the function `sayHello` print exactly `Hello, World!` to the console.

## Description

Printing "Hello, World!" is the classic first step in every programming
language, and today it's your turn. In JavaScript, `console.log()` prints
whatever you put between the parentheses. Text always goes between quotes:

```js
console.log("like this");
```

## Examples

| When you call | It prints       |
| ------------- | --------------- |
| `sayHello()`  | `Hello, World!` |

## What the tests check

- prints "Hello, World!" to the console

## ⚠️ Watch out

The text must be **exactly** `Hello, World!`: capital H, capital W, a comma,
and an exclamation mark. Tests are very precise friends.
